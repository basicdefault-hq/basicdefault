Senko Timer

A calm, repeatable timer. Set a time on the ripple dial, save it with a name, and run it again in one tap. While it runs, a stick of incense burns down in a bowl.

  • Ripple dial. Set the time by feel instead of typing numbers.
  • Saved timers. Name the ones you use and start them in one tap.
  • Steps and repeats. Chain steps like work and rest, and run them as many times as you need.
  • Lock Screen and Dynamic Island. Keep an eye on the time without opening the app.
  • Made for every fold. Its own layout closed, open and propped up like a tent, and on a regular iPhone too.
