# BDHQ logo

Four tiles that flip into the letters B, D, H and Q. The dot is the one constant: the fourth tile when it's tiles, the Q's tail when it's letters.

## Files

| File | Use |
| --- | --- |
| `bdhq-letters.svg` / `-light.svg` | Main logo, 64px and larger. Deep green for light backgrounds; `-light` (cream with a blush dot) for sage or dark backgrounds. |
| `bdhq-tiles.svg` / `-light.svg` | Small sizes, below 64px, where the letter cut-outs blur. |
| `bdhq-animated.svg` / `-light.svg` | Loops tiles to letters and back, one tile at a time. Shows the letters, still, for people who turn off motion. |
| `bdhq-row.svg` / `-light.svg` | Horizontal logo: the letters in one row. For headers, banners and video end cards. |
| `bdhq-row-cursor.svg` / `-light.svg` | The row with the Q's tail blinking like a text cursor. For intros and hero spots; still, it's the plain row. |
| `bdhq-row-animated.svg` / `-light.svg` | The row flipping between plain tiles and letters, one tile at a time. |
| `bdhq-avatar-tiles.svg`, `bdhq-avatar-letters.svg` | Round avatars: cream on sage. |
| `favicon.svg` | Site favicon: the round tiles avatar. Copied to the site root, with `favicon-48.png` as a fallback. |
| `apple-touch-icon.svg` | iPhone home-screen icon: cream letters on a full sage square (iOS rounds the corners). Exported to the site root as `apple-touch-icon.png`. |
| `png/` | PNG exports: 800px avatars (YouTube and socials), 1024px marks and a 1624px horizontal row, all with transparent backgrounds. |

## Rules

- **Size:** letters at 64px and up, tiles below that. The horizontal row needs at least 32px of height for the letters to read.
- **Colours:** deep green `#3E4D44`, cream `#F5E4D7`, sage `#839788` (the dot on light backgrounds), dark sage `#73877B` (avatar and dark backgrounds), blush `#E5D1D0` (the dot on sage).
- **Space:** keep clear space around the mark of at least half a tile.
