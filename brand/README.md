# BDHQ logo

Four tiles that flip into the letters B, D, H and Q. The dot is the one constant: the fourth tile when it's tiles, the Q's tail when it's letters.

## Files

| File | Use |
| --- | --- |
| `bdhq-letters.svg` / `-light.svg` | Main logo, 64px and larger. Deep green for light backgrounds; `-light` (cream with a blush dot) for sage or dark backgrounds. |
| `bdhq-tiles.svg` / `-light.svg` | Small sizes, below 64px, where the letter cut-outs blur. |
| `bdhq-animated.svg` / `-light.svg` | Loops tiles to letters and back, one tile at a time. Shows the letters, still, for people who turn off motion. |
| `bdhq-avatar-tiles.svg`, `bdhq-avatar-letters.svg` | Round avatars: cream on sage. |
| `favicon.svg` | Site favicon (tiles). Switches to light tiles in dark browser chrome. Copied to the site root. |
| `png/` | PNG exports: 800px avatars (YouTube and socials), 1024px marks with transparent backgrounds. |

## Rules

- **Size:** letters at 64px and up, tiles below that.
- **Colours:** deep green `#3E4D44`, cream `#F5E4D7`, sage `#839788` (the dot on light backgrounds), dark sage `#73877B` (avatar and dark backgrounds), blush `#E5D1D0` (the dot on sage).
- **Space:** keep clear space around the mark of at least half a tile.
